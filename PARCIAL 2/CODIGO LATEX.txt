\begin{frame}{¿Qué es una Máquina de Estado Finita (FSM)?}
  \begin{block}{Definición y Conceptos Fundamentales}
    Representa un sistema como un conjunto de \textbf{estados} y \textbf{transiciones} que dependen de las entradas, generando salidas asociadas. Es la representación de un circuito secuencial particular.
    \begin{itemize}
      \item \textbf{Estado:} Conjunto único de valores medidos en un sistema digital.
      \item \textbf{Ramificación:} El paso del estado presente al estado siguiente.
      \item \textbf{Diagrama de estado:} Ilustración del funcionamiento mediante "burbujas" y "flechas".
      \item \textbf{Importancia:} Cualquier circuito con memoria (desde un flip-flop hasta una computadora) puede ser considerado una FSM.
    \end{itemize}
  \end{block}
\end{frame}

\begin{frame}{State Machine Design: The Electric Train Controller}
  \begin{block}{Planteamiento del Problema}
    Se tiene un sistema de trenes eléctricos compuesto por dos trenes, denominados \textbf{Tren A} y \textbf{Tren B}, que se desplazan en un circuito con múltiples segmentos de vía interconectados.

    El sistema incluye un \textbf{segmento común (Track 2)}, el cual puede ser ocupado por ambos trenes, lo que introduce el riesgo de \textbf{colisiones} si no se controla adecuadamente su acceso.
  \end{block}
\end{frame}


\begin{frame}{Objetivo del Controlador}
  \begin{block}{Diseño de la FSM}
    Diseñar una \textbf{máquina de estados finita (FSM)} que:
    \begin{itemize}
      \item Controle el movimiento de ambos trenes mediante señales de dirección.
      \item Gestione el estado de los \textbf{switches} para enrutar correctamente los trenes.
      \item Garantice que \textbf{solo un tren ocupe el segmento común} en cualquier instante.
      \item Evite colisiones y descarrilamientos durante la operación del sistema.
    \end{itemize}
  \end{block}
\end{frame}

\begin{frame}{Introducción}
  \begin{block}{Contexto General}
    Las \textbf{máquinas de estados finitas (FSM)} constituyen una herramienta fundamental en el diseño de sistemas digitales secuenciales, permitiendo modelar comportamientos complejos mediante la definición de estados y transiciones controladas por entradas.

    En aplicaciones reales, como sistemas de control y automatización, las FSM son ampliamente utilizadas para garantizar un funcionamiento seguro, predecible y eficiente.
  \end{block}

  \begin{block}{Aplicación al Problema}
    En este trabajo, se aborda el diseño de un controlador para un sistema de trenes eléctricos, en el cual dos trenes comparten parcialmente la vía.

    Mediante el uso de una FSM, se busca gestionar el movimiento de los trenes y el estado de los switches, asegurando una operación libre de colisiones y respetando las restricciones del sistema físico.
  \end{block}
\end{frame}

\begin{frame}{Descripción del Problema}
  \begin{block}{Sistema de Trenes Eléctricos}
    El problema consiste en el diseño de un controlador digital para un sistema de trenes eléctricos compuesto por dos trenes independientes, denominados \textbf{Tren A} y \textbf{Tren B}, que se desplazan sobre una red de vías interconectadas.

    Ambos trenes operan en la misma infraestructura física, compartiendo parcialmente su recorrido, lo que introduce condiciones críticas de seguridad que deben ser gestionadas mediante un sistema de control lógico.
  \end{block}
\end{frame}

\begin{frame}{Estructura del Sistema}
  \begin{block}{Segmentos de la Vía}
    La red de trenes está dividida en múltiples segmentos, entre los cuales destaca un \textbf{segmento común (Track 2)}, el cual puede ser accedido por ambos trenes.

    Este segmento representa un punto crítico del sistema, ya que:
    \begin{itemize}
      \item Es compartido por ambos trenes.
      \item Existe riesgo de \textbf{colisión} si no se regula su acceso.
      \item Requiere coordinación estricta mediante lógica de control.
    \end{itemize}
  \end{block}
\end{frame}


\begin{frame}{Sensores del Sistema}
  \begin{block}{Detección de Trenes}
    El sistema dispone de cinco sensores digitales (\textbf{S1, S2, S3, S4, S5}) ubicados en puntos estratégicos de la vía, los cuales permiten detectar la presencia de los trenes.

    \begin{itemize}
      \item Cada sensor se activa cuando un tren se encuentra en su proximidad.
      \item Las señales de los sensores \textbf{no son instantáneas}, sino que permanecen activas durante varios ciclos de reloj.
      \item Esto implica que el diseño debe considerar \textbf{transiciones de estado cuidadosas} para evitar interpretaciones erróneas.
    \end{itemize}
  \end{block}
\end{frame}

\begin{frame}{Señales de Control del Sistema}
  \begin{block}{Actuadores del Sistema}
    El controlador genera señales de salida que determinan el comportamiento del sistema:

    \begin{itemize}
      \item \textbf{Dirección de los trenes:}
      \begin{itemize}
        \item Tren A: DA1-DA0
        \item Tren B: DB1-DB0
      \end{itemize}
      \item \textbf{Configuración de switches:} SW1, SW2 y SW3
    \end{itemize}

    Estas señales permiten:
    \begin{itemize}
      \item Detener o poner en movimiento los trenes.
      \item Controlar la dirección de desplazamiento.
      \item Redirigir los trenes entre vías internas y externas.
    \end{itemize}
  \end{block}
\end{frame}

\begin{frame}{Enfoque de Solución}
  \begin{block}{Uso de Máquina de Estados}
    Para resolver este problema, se emplea una \textbf{máquina de estados finita (FSM)}, la cual permite modelar el comportamiento del sistema mediante estados y transiciones basadas en las señales de entrada.

    La FSM:
    \begin{itemize}
      \item Supervisa continuamente los sensores.
      \item Decide cuándo permitir el acceso al segmento común.
      \item Controla la detención y movimiento de los trenes.
      \item Garantiza el cumplimiento de todas las restricciones del sistema.
    \end{itemize}
  \end{block}
\end{frame}

\begin{frame}{Análisis del Diagrama de Estados}
  \begin{block}{Interpretación del Comportamiento}
    \begin{itemize}
      \item La máquina de estados está compuesta por cinco estados principales: \textbf{ABout, Ain, Bin, Astop y Bstop}.
      \item Las transiciones dependen de las combinaciones de los sensores (\textbf{S1, S2, S3, S4}).
      \item Los estados \textbf{Ain} y \textbf{Bin} representan el ingreso al segmento común.
      \item Los estados \textbf{Astop} y \textbf{Bstop} detienen un tren para evitar conflictos en la vía.
      \item El estado \textbf{ABout} representa la operación normal sin conflicto en el segmento compartido.
    \end{itemize}
  \end{block}
\end{frame}


\begin{frame}{Descripción del Código Desarrollado}
  \begin{block}{Estructura General}
    El controlador del sistema de trenes fue implementado en \textbf{VHDL} utilizando una arquitectura basada en \textbf{máquinas de estados finitas (FSM)}.

    El diseño se compone de:
    \begin{itemize}
      \item Definición de la entidad (entradas y salidas)
      \item Declaración de estados y señales internas
      \item Proceso secuencial para la transición de estados
      \item Lógica combinacional para definir las salidas
    \end{itemize}

    Este enfoque permite modelar el comportamiento del sistema de forma clara, modular y sintetizable en hardware.
  \end{block}
\end{frame}

LIBRARY IEEE;
USE IEEE.STD_LOGIC_1164.ALL;
USE IEEE.STD_LOGIC_ARITH.ALL;
USE IEEE.STD_LOGIC_UNSIGNED.ALL;

ENTITY Tcontrol IS
PORT(
  reset, clock,
  sensor1, sensor2, sensor3, sensor4, sensor5 : IN STD_LOGIC;
  switch1, switch2, switch3 : OUT STD_LOGIC;
  dirA, dirB : OUT STD_LOGIC_VECTOR(1 DOWNTO 0)
);
END Tcontrol;
\end{verbatim}

BEGIN
\end{verbatim}
  \end{block}

  \begin{block}{Interpretación}

\begin{frame}[fragile]{Proceso Secuencial}
  \begin{block}{Transición de Estados}
    \tiny
\begin{verbatim}
PROCESS (reset, clock)
BEGIN
  IF reset = '1' THEN
    state <= ABout;

  ELSIF rising_edge(clock) THEN

    CASE state IS
\end{verbatim}
  \end{block}

  \begin{block}{Interpretación}
    \begin{itemize}
      \item Se implementa un registro de estado con flip-flops.
      \item El cambio de estado ocurre en el flanco positivo del reloj.
      \item Se define un estado inicial mediante reset.
    \end{itemize}
  \end{block}
\end{frame}


\begin{frame}[fragile]{Lógica de Transición}
  \begin{block}{Estado ABout}
    \tiny
\begin{verbatim}
WHEN ABout =>
  CASE sensor12 IS
    WHEN "00" => state <= ABout;
    WHEN "01" => state <= Bin;
    WHEN "10" => state <= Ain;
    WHEN "11" => state <= Ain;
    WHEN OTHERS => state <= ABout;
  END CASE;
\end{verbatim}
  \end{block}

  \begin{block}{Interpretación}
    \begin{itemize}
      \item Se decide qué tren entra al track común.
      \item Se evalúan sensores S1 y S2 simultáneamente.
    \end{itemize}
  \end{block}
\end{frame}


\begin{frame}[fragile]{Estados de Control}
  \begin{block}{Astop y Bstop}
    \tiny
\begin{verbatim}
WHEN Astop =>
  IF sensor3 = '1' THEN
    state <= Ain;
  ELSE
    state <= Astop;
  END IF;

WHEN Bstop =>
  IF sensor4 = '1' THEN
    state <= Bin;
  ELSE
    state <= Bstop;
  END IF;
\end{verbatim}
  \end{block}

  \begin{block}{Interpretación}
    \begin{itemize}
      \item Se detiene un tren hasta que el otro libere el track común.
      \item Se usan sensores para reanudar el movimiento.
    \end{itemize}
  \end{block}
\end{frame}


\begin{frame}[fragile]{Procesamiento de Sensores}
  \begin{block}{Agrupación de Entradas}
    \tiny
\begin{verbatim}
sensor12 <= sensor1 & sensor2;
sensor13 <= sensor1 & sensor3;
sensor24 <= sensor2 & sensor4;
\end{verbatim}
  \end{block}

  \begin{block}{Interpretación}
    \begin{itemize}
      \item Se combinan sensores para simplificar la lógica.
      \item Permite evaluar múltiples condiciones en una sola comparación.
    \end{itemize}
  \end{block}
\end{frame}

\begin{frame}[fragile]{Lógica de Salidas}
  \begin{block}{Asignación con WITH SELECT}
    \tiny
\begin{verbatim}
WITH state SELECT
switch1 <= '0' WHEN ABout,
           '0' WHEN Ain,
           '1' WHEN Bin,
           '1' WHEN Astop,
           '0' WHEN Bstop;
\end{verbatim}
  \end{block}

  \begin{block}{Interpretación}
    \begin{itemize}
      \item Las salidas dependen únicamente del estado actual.
      \item Se implementa una máquina de tipo Moore.
    \end{itemize}
  \end{block}
\end{frame}

\begin{frame}[fragile]{Control de Movimiento}
  \begin{block}{Dirección de los Trenes}
    \tiny
\begin{verbatim}
WITH state SELECT
dirA <= "01" WHEN ABout,
        "01" WHEN Ain,
        "01" WHEN Bin,
        "00" WHEN Astop,
        "01" WHEN Bstop;

WITH state SELECT
dirB <= "01" WHEN ABout,
        "01" WHEN Ain,
        "01" WHEN Bin,
        "01" WHEN Astop,
        "00" WHEN Bstop;
\end{verbatim}
  \end{block}

  \begin{block}{Interpretación}
    \begin{itemize}
      \item "01" indica movimiento hacia adelante.
      \item "00" indica detención del tren.
      \item Cada estado define el comportamiento de ambos trenes.
    \end{itemize}
  \end{block}
\end{frame}
